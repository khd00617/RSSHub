# Lessons

## 2026-09-09: OpenCode Go セッションヘッダー要件による youtube-official 要約エラー

### 現象

`/youtube-official/channel/:id` の description が「要約を取得できませんでした」になった(2026-09-07頃から)。

### 原因

1. OpenCode Go API が `x-opencode-session` ヘッダーと独自 User-Agent を必須化(~2026-09-07)。欠落で `400 MissingSessionID`。
2. API 失敗時、`summarizeVideo()` がフォールバック(エラーメッセージ)を返し、それが `cache.tryGet` で**30日間キャッシュ**されていた。
3. さらに YouTube 公式 RSS が断続的に 404 を返し、フォールバック経由のアイテムは description 空だったため、エラーメッセージが AI への「文字起こし」として送信され、AI の「文字起こしなし」応答もキャッシュされた。

### 対策

- `x-opencode-session` + `User-Agent` ヘッダーを追加
- 失敗時は例外を投げてキャッシュしない設計に変更
- キャッシュキー v4→v5、ルートキャッシュ v2→v3 に世代更新

### ルール(自分への戒め)

- **外部 API の失敗結果をキャッシュするな**。`cache.tryGet` の getValueFunc 内で失敗を握りつぶしてフォールバックを返すと、失敗が長期キャッシュされる。失敗は throw してキャッシュ外で処理する。
- **外部 SaaS のドキュメント更新(特にクライアント要件)は監視対象**。突然 400 になる仕様変更は「一昨日から壊れた」系バグの定番。
- エラーメッセージのプレースホルダーを後続処理(AI 入力等)に流用しない。表示用とデータ用を分離する。

## 2026-09-09: フォールバック経路で最新動画が消える問題

### 現象

youtube-official のフォールバック経路で、最新動画(Sep 7-9)が消え古い動画(Aug)が表示される。

### 原因(複合)

1. YouTube InnerTube の動画タブ応答が新形式 `LockupView` に移行 → 旧コードの `'video_id' in video` フィルタで全件除外(youtubei ソースが死んでいた)
2. このチャンネルの最新動画は**ほぼ全てライブ配信**でライブタブにのみ存在(videos タブの最新は 8/30)
3. ライブタブの日時形式「7 時間前 に配信済み」は**前と に配信済み の間にスペースがある**ため正規化パターンがマッチせず parseRelativeDate が失敗
4. 日時抽出の文字クラス `[秒分時日週月]` に「年」が欠落 →「1 年前」が未検出
5. マージキーがソース間で不一致(RSS guid `yt:video:ID` / ページ guid `ID` / youtubei は link のみ)→ 重複アイテム発生

### 対策

RSS リトライ 3 回 / ライブタブマージ(includeLive オプション) / ページ解析リトライ / LockupView 対応 / ja ロケール化 / 日時正規化強化(スペース含む配信済み・か月ヶ月・年) / マージキーを動画 ID に正規化 / 日時補間

### ルール(自分への戒め)

- **日時パースの失敗は文字コードレベルで確認する**。不可視文字・スペースの有無は mojibake したログでは見えない。`Array.from(text).map(ch => U+...)` で文字コードを出力して比較する。
- **複数ソースをマージする場合はキーの正規化を最初に設計する**。ソースごとに ID 形式が違うと重複除去が静かに壊れる。
- **「〜が取得できない」系バグはまず各ソース単体で実データをダンプする**。推測で直すと何度も外す。
